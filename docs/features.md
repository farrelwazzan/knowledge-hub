# Features

## Knowledge Entry

Pengguna dapat:

* Create Knowledge Entry
* View Knowledge Entry
* Update Knowledge Entry
* Delete Knowledge Entry

Setiap Knowledge Entry dapat menyimpan:

* Title
* Source type
* Source link
* Category
* Tags
* Personal notes

## Organization

Knowledge dapat diorganisasi menggunakan:

* Categories
* Tags

## Retrieval

Pengguna dapat menemukan kembali knowledge menggunakan:

* Search
* Filter by category
* Filter by tags
* Sorting

## Personal Context

Pengguna dapat menambahkan catatan pribadi untuk menyimpan konteks atau alasan mengapa informasi tersebut penting.

## Future Features

Fitur berikut dapat dipertimbangkan setelah core application selesai:

* Recently viewed knowledge
* Knowledge activity history
* Knowledge activity insights
* Improved search
