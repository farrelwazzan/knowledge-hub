# Knowledge Hub

## Personal Knowledge Retrieval System

Knowledge Hub adalah aplikasi web yang membantu pengguna menyimpan dan menemukan kembali informasi atau pengetahuan yang pernah mereka anggap penting.

Informasi seperti artikel, video YouTube, dokumentasi, repository GitHub, website, dan catatan pribadi sering kali tersebar di berbagai tempat dan sulit ditemukan kembali ketika dibutuhkan.

Knowledge Hub menyediakan satu tempat untuk menyimpan informasi tersebut sebagai **Knowledge Entry**, lengkap dengan sumber, kategori, tag, dan catatan pribadi.

## Core Concept

> **Capture → Organize → Retrieve**

Pengguna dapat:

* Menyimpan informasi penting sebagai Knowledge Entry
* Menambahkan sumber atau link
* Mengelompokkan knowledge menggunakan category dan tags
* Menambahkan catatan atau konteks pribadi
* Mencari dan menemukan kembali knowledge yang pernah disimpan

## Main Goal

Membantu pengguna tidak kehilangan informasi atau pengetahuan yang pernah mereka temukan dan memudahkan mereka menemukannya kembali ketika dibutuhkan.
