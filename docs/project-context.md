# Project Context

## Project Name

Knowledge Hub

## Project Type

Personal Knowledge Retrieval System

## Overview

Knowledge Hub adalah aplikasi web yang membantu pengguna menyimpan dan menemukan kembali informasi atau pengetahuan yang pernah mereka anggap penting.

Informasi dapat berasal dari berbagai sumber seperti artikel, video YouTube, dokumentasi, repository GitHub, website, atau catatan pribadi.

Fokus utama aplikasi bukan hanya menyimpan informasi, tetapi membantu pengguna menemukan kembali informasi tersebut ketika dibutuhkan.

## Problem

Pengguna sering menemukan informasi yang berguna, tetapi seiring waktu informasi tersebut dapat:

* Terlupakan
* Tersimpan di berbagai tempat
* Sulit ditemukan kembali
* Kehilangan konteks mengapa informasi tersebut penting

## Solution

Knowledge Hub memungkinkan pengguna menyimpan informasi sebagai Knowledge Entry.

Setiap Knowledge Entry dapat memiliki:

* Title
* Source
* Link
* Category
* Tags
* Personal notes

Informasi tersebut kemudian dapat dicari dan ditemukan kembali melalui fitur pencarian dan pengorganisasian.

## Core Flow

> Capture → Organize → Retrieve

1. Pengguna menemukan informasi.
2. Pengguna menyimpannya sebagai Knowledge Entry.
3. Pengguna menambahkan category, tags, dan personal context.
4. Sistem menyimpan knowledge tersebut.
5. Pengguna dapat mencari dan menemukan kembali knowledge ketika dibutuhkan.

## Main Goal

Membantu pengguna tidak kehilangan pengetahuan yang pernah mereka temukan dan memudahkan mereka menemukannya kembali ketika dibutuhkan.

## Project Scope

Knowledge Hub berfokus pada personal knowledge management dan retrieval.

Project tidak berfokus pada:

* Social media
* Collaboration
* Complex team workspace
* File management system yang kompleks

Fokus utama tetap pada pengalaman menyimpan, mengorganisasi, dan menemukan kembali knowledge.
